# WinPaint 功能规格（源自 Windows 画图界面逆向）

> 最后更新:2026-11-15
> 证据来源:`raw/` 下 4 张 Windows 11 新版画图 11.2601.441.0 界面截图,分析过程见 `wiki/` 8 个主题页。

## 0. 目标

在 macOS 上提供一个**直白、够用、不折腾**的画图工具:改大小、裁边、调色、画两笔,不用开 Photoshop。

Windows 画图的全部功能不必 1:1 复刻,但**截图里出现的每一类交互都要有 macOS 对应物**,要么实现,要么在菜单里明确标注"未支持"。

## 1. 界面布局对照

| Windows 画图 | macOS 实现 | 优先级 |
|-------------|-----------|-------|
| 顶部菜单栏(文件/编辑/查看)+ 右侧反馈/设置 | SwiftUI `MenuBarExtra`? 否 → AppKit 菜单栏 + SwiftUI `Commands` | P0 |
| 横向功能区(9 组工具) | 顶部水平工具条,分组用竖线隔开,组名贴在下方 | P0 |
| 左侧浮动「工具选项」竖条(笔刷大小 / 填充色) | 画布左侧浮动竖条,同上布局 | P0 |
| 右侧「层」面板(⊕ 新建 + 缩略图列表) | 右侧可折叠面板 | P0 |
| 底部状态栏(尺寸 / 大小 / 缩放) | 底部状态栏,同字段顺序 | P0 |
| 画布 + 选区控制柄 + 网格 + 标尺 | SwiftUI `Canvas` + 自定义变换 | P0 |

## 3. 与 Windows 画图的关键差异(有意为之)

| 项 | Windows 画图 | WinPaint | 理由 |
|----|------------|----------|------|
| 坐标原点 | 左上 | **左下(Core Graphics 原生)** | 避开位图上下翻转错位;鼠标坐标转换时统一翻一次 |
| 快捷键 | Ctrl 组合 | **⌘ 为主**(macOS 惯例),保留 Ctrl+R / Ctrl+G 网格标尺 | 平台惯例 |
| 文件格式 | PNG/BMP/TIFF/GIF/JPEG | 同 | — |
| 项目格式 | .paintproj | **.winpaint**(JSON + PNG 图层) | 自定义,便于多图层往返 |
| 撤销粒度 | 一步一动作 | **区域快照式**(只存被改动的矩形区域) | 全量快照内存爆炸,区域快照与 Windows 行为等价但省内存 |

## 4. 验收标准(v1 可交付)

1. `swift build` 零错误零警告
2. `scripts/build-app.sh` 产出 `dist/WinPaint.app`,用 **Apple Distribution (BP6XLRFH4K)** 签名,`codesign --verify` 通过
3. `spctl -a -vvv` 判定为 `accepted`(Developer ID 生效)
4. 打开后可:新建 → 画 → 撤销 → 保存 → 重新打开,图形与图层结构完整
5. 全部 P0 功能可用;P1/P2 在「功能规格」表内标注状态,不隐藏
