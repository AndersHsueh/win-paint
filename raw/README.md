# raw/

> **LLM 只读目录。本目录下任何文件禁止修改。**

本目录存放项目的**原始素材**,包括但不限于:

- 商务对话记录 / 邮件 / 微信截图(转文字)
- 客户方提供的需求清单(xlsx/docx)
- 会议纪要(需求评审、需求澄清、阶段复盘)
- 客户方提供的业务样例(模板表、真实数据 xlsx)
- 部署日志、SOP、操作手册
- 第三方产品的介绍材料 / 对比资料 / 培训素材
- 合同 / 报价 / 招投标相关原件

## 命名约定

- 商务对话:`商务对话记录.md`
- 会议纪要:`<类型>-<MMDD>.md`(如 `需求评审会-0612.md`)
- 客户样例:`raw/<客户方提供日期>/` 子目录(如 `raw/20260623客户提供了一些工作中的实际文件作为样例/`)
- 第三方材料:`<产品名>_<主题>.md`(如 `codebuddy_产品概览.md`)

## LLM 行为约束

1. **只读** — 用 Read / grep / cat,不要 Edit / Write 任何 raw 下文件
2. **发现问题只注 wiki** — 发现 raw 错别字、矛盾、格式问题 → 在对应 wiki 主题页加 `> 已过时:YYYY-MM-DD 起 raw/X 处有 Y 问题`
3. **新文件入仓必走 Ingest 工作流** — 详见 [[../wiki/工作流-ingest-query-lint#一-ingest-工作流]]
4. **保留原始组织结构** — 客户方提供的子目录(如 `raw/20260623*/`)原样保留,不要散开重命名
