# 画图文件菜单

> 最后更新:2026-11-15

## 摘要

本主题完整记录 Windows 11 新版画图「文件」菜单的全部 12 个条目与快捷键。菜单按三段分隔:文档操作段(新建 / 打开 / 导入到画布 / 最近使用的文件 / 保存 / 另存为 / 另存为项目)、输出段(打印 / 共享)、系统段(设置为桌面背景 / 图像属性 / 退出)。相比旧版 Win32 画图新增了「导入到画布」「另存为项目」「共享」「设置为桌面背景」四个条目。菜单入口在 [[画图主界面布局]],快捷键体系与 [[画图查看菜单]] 相互独立。

## 二、三个能力点解读

### 「导入到画布」

与「打开」的本质区别:打开会新建一个文档,导入是把外部图像叠加进当前画布。本次会话的图层堆叠中出现「图像层 + 空白层」两层结构,与导入行为吻合,详见 [[画图层与Copilot]]。

### 「另存为项目」

Windows 11 新版画图引入的项目格式,用于保存多图层画作(含图层结构),与「另存为」保存为单张位图不同。这是该版本区别于旧版画图的标志性条目之一。

### 「设置为桌面背景」

把当前画布内容设为桌面壁纸,带子菜单(可选适配方式)。

## 三、与画布状态的耦合

菜单展开时,底层画布仍可见且图像仍处于选中态。状态栏读数 1200 × 630 像素、118.2KB,与 [[画图主界面布局]] 记录的读数一致。

## 四、快捷键汇总

本菜单暴露 5 个快捷键:Ctrl+N(新建)、Ctrl+O(打开)、Ctrl+S(保存)、Ctrl+Shift+S(另存为项目)、Ctrl+E(图像属性)。其中 Ctrl+Shift+S 与 Ctrl+E 是新版画图新增或沿用的键位,与旧版 Win32 画图一致。查看菜单另有 3 个,见 [[画图查看菜单]]。
