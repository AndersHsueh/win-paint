# 画图功能区工具组

> 最后更新:2026-11-15

## 摘要

本主题逐组拆解 Windows 11 新版画图的功能区(ribbon)。功能区从左到右共 9 组:选择、图像、工具、画笔、形状、填充与粗细、颜色、Copilot、层,组间以竖直分隔线区隔,组名标签统一贴在组底部。形状库与图像组带下拉箭头,表示存在折叠的更多选项。本页是 [[画图主界面布局]] 的展开,其余主题页按需引用其中具体组。

## 一、选择组

两个图标,纵向排列:

- 矩形虚线选框 + 下拉箭头(矩形选择)
- 斜纹填充矩形 + 箭头(手绘/自由形状选择)

## 二、图像组

四个按钮:

| 按钮 | 形态 | 下拉 | 备注 |
|------|------|------|------|
| 裁剪 | 两个交叠矩形带角括号 | 无 | |
| 旋转 | 弧形箭头 + 蓝色角 | 有 | |
| 翻转 | 蓝色填充三角 | 有 | |
| 调整大小 | 虚线矩形带箭头 | 无 | 本次截图中呈蓝色高亮,属可用/已激活态 |

## 三、工具组

2×3 排列的六个独立工具,无下拉:

铅笔、填充(油漆桶)、文本(A)、橡皮擦、取色器、放大镜。

## 四、画笔组

单一大号画笔图标,带下拉箭头,且带蓝色高亮边框 —— 表示当前激活工具就是画笔。

## 五、形状组

图标库,多行多列,右侧带垂直滚动条,说明形状总数超出可见区:

- 第 1 行:直线、曲线、椭圆、矩形、圆角矩形
- 第 2 行:直角三角形、三角形、菱形、五边形、六边形(末位被滚动条部分遮挡)
- 第 3 行:六边形、右箭头、左箭头、上箭头、下箭头
- 第 4 行:仅露出上半部分,确认为更多形状

> 待澄清:第 4 行及以后的具体形状因被裁切无法确认,已登记到 [[画图界面待澄清项]] 第 1 项。

## 六、填充与粗细(形状组右侧两个下拉)

- 填充样式下拉:图标为「油漆桶 + 笔」
- 粗细下拉:图标为墨迹条纹

> 推断:这两个下拉分管形状的填充效果与线宽控制。截图未展开,选项清单未知,见 [[画图界面待澄清项]] 第 2 项。

## 七、斜线图案下拉

位于形状组与颜色组之间,图标为多条平行斜线 + 下拉箭头。

> 推断:对应不透明度或混合模式。截图未展开,功能未确认,见 [[画图界面待澄清项]] 第 3 项。

## 八、颜色组

| 元素 | 说明 |
|------|------|
| 主色槽 | 大圆,当前黑色,带蓝色高亮环 |
| 副色槽 | 大圆,白色,位于主色槽正下方 |
| 标准色板 | 2 行 × 10 列 |
| 自定义色位 | 第 3 行 10 个空心圆(未使用的自定义色槽) |
| 彩虹轮 +「+」 | 打开自定义颜色选择器 |

彩虹轮实测几何(原版截图逐像素):

- 外框 x 1201..1234 / y 128..161(34×34)
- 色相环为**椭圆**,中心 (1216.8, 146.95),半径 15.7 / 15.6(原截图本身有约 3% 纵向压缩)
- 「+」徽标圆心 (1226.4, 135.8),半径 7.6(深灰圈 d≈14 + 白盘 d≈11 + 灰十字)
- 同一半径上 V 值最大差 30 —— 不是纯色相环,带明暗过渡;白心位于几何中心附近
- 结论:解析式重建最多逼近到 meanΔ≈5~8,肉眼仍可辨偏差 → **按位图资源抠取原版像素**
  (边缘像素本身即「色相⊕底色」的混合色,直接烘成不透明最接近原版渲染)

标准色板实测坐标:第 1 行 y=114、第 2 行 y=144,色块中心 x = 956 / 986 / 1016 / 1046 /
1076 / 1106 / 1136 / 1166(两行同列),直径 20px,外圈 = 本色 × 0.87。

标准色板逐格读数:

- 第 1 行:黑、灰、深红、红、橙、黄、绿、天蓝、靛蓝、紫
- 第 2 行:白、浅灰、棕、粉、橙黄、米黄、黄绿、青、蓝灰、淡紫

## 九、Copilot 组

彩虹色 Copilot 徽标 + 下拉箭头。它与「层」组同为独立分组而非普通工具按钮,暗示展开的是侧边面板而非立即执行某个动作。详见 [[画图层与Copilot]]。

## 十、层组

堆叠图层图标 + 下拉箭头,展开后即右侧层面板,详见 [[画图层与Copilot]]。
