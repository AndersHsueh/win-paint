# 画图主界面布局

> 最后更新:2026-11-15

## 摘要

本主题描述 Windows 11 新版「画图」(Microsoft Paint) 11.2601.441.0 的主窗口骨架。窗口自上而下分为标题栏、菜单栏、功能区(ribbon)、画布工作区、状态栏五层，另有左侧浮动「工具选项」条与右侧「层」面板两处可展开侧栏。功能区按 9 个业务组横向排布：选择 / 图像 / 工具 / 画笔 / 形状 / 填充与粗细 / 颜色 / Copilot / 层。本页是所有界面细节的母页，其余主题页在它之上展开。

## 一、窗口层级结构

| 层级 | 位置 | 内容 |
|------|------|------|
| 标题栏 | 最上 | 应用图标 + 文档标题 + 最小化/最大化/关闭 |
| 菜单栏 | 标题栏下 | 文件 / 编辑 / 查看 + 快速动作图标 |
| 功能区 | 菜单栏下 | 9 组工具,逐组拆解见 [[画图功能区工具组]] |
| 画布工作区 | 中部 | 图像 + 选区控制柄 + 左侧浮动工具条 |
| 状态栏 | 最下 | 画布尺寸 / 文件大小 / 缩放 |

## 六、状态栏

从左到右共 5 组读数:

1. 指针形状图标(当前光标模式指示)
2. 虚线方括号图标(选区范围指示)
3. 图片图标 + `1200 × 630像素`
4. 软盘图标 + `大小: 118.2KB`
5. 右侧一组:`[o]` 取景框图标(适应窗口)、`100%` 缩放下拉、缩小镜、缩放滑轨、放大镜

> 关键语义:第 4 项的 `118.2KB` 是**图片编码后的文件体积**,不是裸位图体积
> (1200×630×4 = 3.02MB)。118.2KB 恰好是这张图 PNG 编码后的字节数,
> 说明 Windows 画图的状态栏报的是「当前图片存成文件会有多大」。
> 复刻时必须照这个语义实现,否则读数量级会差 25 倍。
